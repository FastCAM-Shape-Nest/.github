## Four Beats

1. **Name the desk.** Give the FastCAM cutting desk a short title before the operator starts.
2. **Pin the live shapes.** Keep current parts on FastCAM shape nest and leave unused plates aside.
3. **Read the NC.** Open FastCAM NC output before you move a shape that already has a mark.
4. **Check the marking.** Read FastCAM plate marking before you archive a nest.
5. **Keep the pair.** Leave NC and marking on the same FastCAM cutting desk.
6. **Leave the table ready.** Keep the marked plate aligned with FastCAM shape nest.
7. **Close the loop.** Clear finished plates so the next FastCAM visit does not start with a search.

## First Questions

**Does FastCAM replace every other program?**
No. FastCAM sits beside the table list, browser, and files you already use.

**Can two people share one computer?**
Yes. Each person keeps a separate FastCAM profile.

**What should a new user try first?**
One small FastCAM shape nest today, then the same NC output tomorrow.

**Does NC output leave the cutting desk?**
No. FastCAM NC output stays with FastCAM plate marking on that desk.

**Is FastCAM only for a finished plate?**
No. FastCAM can hold a single shape while the rest of the table stays off the board.

**Does the operator need a second file for marking?**
No. FastCAM keeps the nest and the plate marking on this cutting desk.

## Field Note

FastCAM is easier to trust when the cutting desk stays smaller than the folder it came from. A named plate shows what is active, the shape pins show what you will cut today, and the closing note tells the next person which NC output changed.

The same loop fits a single nest, a marked plate, or a table shared by two people. Open the last FastCAM cutting desk, finish one NC output, and leave fewer loose shape files than you found.

A review should not have to guess which mark belongs to the open nest. Keep that pair together inside FastCAM.

## One Real Pass

Pick a plate that already has a name. Open it in FastCAM, keep only those shapes on the nest, and finish one NC output you can see.

If the pass feels crowded, the set is too wide. Drop anything that belongs to a different table and leave it out of this FastCAM cutting desk.
